# MAHA Design System

## Visual Principles
- Official, administrative, and modern
- High information density with clarity
- Restrained styling over decorative effects
- Accessibility-first interaction patterns

## Color and Tone
- Background: white / very light grey
- Primary accent: government-inspired blue
- Typography: dark navy for high contrast
- Status chips use color + text labels (not color-only indicators)

## Component Language
- Government header
- Breadcrumb
- Page title + action bar
- Information cards with thin borders
- Data tables
- Status badges
- Filter bars and search bars
- Tabs, accordions, timelines, checklists
- Alerts and confirmation dialogs

## Interaction Rules
- Predictable navigation
- Keyboard-focus visibility
- Clear form labels and validation messaging
- Compact spacing and consistent hierarchy
- Meaningful empty states and error/success states

## Public vs Authenticated UX
- Public portal: informational and discoverability-focused
- Authenticated workspace: operational records, evidence, approvals, audit logs
