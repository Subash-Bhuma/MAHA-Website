# MAHA Workflows

## Primary Lifecycle
Problem → Discover → Verify → Evaluate → Pilot → Measure → Evidence → Procurement Handoff → Scale

## Vertical Slice Workflow (Implemented)
1. Government officer creates challenge as `Draft`
2. Officer publishes challenge to `Published`
3. System records audit events for each state change
4. Public and internal users can view challenge status and timeline

## Status Models

### Challenge
- Draft
- Published
- Open
- Under Review
- Closed
- Archived

### Application
- Submitted
- Eligibility Review
- Eligible
- Ineligible
- Under Evaluation
- Shortlisted
- Rejected
- Withdrawn

### Pilot
- Planned
- Approved
- Active
- At Risk
- Completed
- Validated
- Not Validated

### Procurement Handoff
- Preparing
- Under Review
- Ready for Handoff
- Handed Off
- Decision Recorded
- Closed

## Human-in-the-Loop Rule
AI recommendations are advisory only. Any eligibility, evaluation, pilot approval, or procurement decision must be taken by authorised officials.
